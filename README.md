# 📊 DecodeLabs-Internship

## 🏷️ Project Title
**E-Commerce Sales Performance & Corporate Diagnostics Audit**

## 📝 Description
This project focuses on the production data pipeline, data sanitization, and advanced Exploratory Data Analysis (EDA) executed on an enterprise E-commerce transactional dataset containing 1,200 unique records. It identifies core revenue metrics, processes multi-criteria channel filtering, and isolates high-value VIP corporate outliers using statistical models.

## ⚙️ How to Run
1. Open the primary data cleaning file `Dataset for Data Analytics(Cleaned).xlsx` to view descriptive statistics.
2. Load the schema into Microsoft SQL Server Management Studio (SSMS) using the database identifier `DecodeLabs_DB`.
3. Open and run the standalone production query script `Decode Labs(Ecomerce_Data).sql` to execute analytical extraction models.
